Python File Organizer Automation Tool

Project Overview

The Python File Organizer Automation Tool automatically organizes files into different folders based on their file extensions. It helps reduce manual work and keeps files organized.

Features

- Organizes images, documents, videos, and audio files.
- Supports Python files.
- Places unrecognized file types into an Others folder.
- Creates category folders automatically.
- Checks whether the selected folder exists.
- Skips duplicate filenames in the destination folder.

Technologies Used

- Python
- Visual Studio Code
- Python os module
- Python shutil module

How to Run

1. Install Python on your computer.

2. Open the project folder in Visual Studio Code.

3. Open the terminal.

4. Run the following command:
   
   "python file_organizer.py"

5. Enter the path of the folder you want to organize.

6. Press Enter and check the results.

Project Files

- "file_organizer.py" — Main Python program.
- "README.md" — Project documentation.

Safety Note

Test the program using a separate folder containing sample files before organizing important files.

Conclusion

This project demonstrates how Python can automate repetitive file-management tasks and improve productivity.
